# Abanoub's first website

A personal landing page built with ChatGPT using plain HTML, CSS, and JavaScript. No installation or build step is needed.

## Open it

Double-click `index.html` to preview the site in a browser.

## Understand the files

- `index.html`: the words, links, and page sections (intro, about, first project, and GitHub link).
- `styles.css`: colors, typography, layout, and adjustments for smaller screens. The color variables are at the top.
- `script.js`: automatically updates the footer year. Everything else works without JavaScript.
- `favicon.svg`: the little icon in the browser tab.
- `.nojekyll`: tells GitHub Pages to serve these static files directly.

## Make your first edit

Open `index.html` in a text editor and change a sentence in the About section. Save it and refresh your browser. On GitHub, open the file, choose the pencil (Edit), change the sentence, and commit the change. A commit is a saved version of the project.

## Publish with GitHub Pages

1. Create a **public** repository named `abanoubmalak2005.github.io` under `abanoubmalak2005`.
2. Upload all files from this folder to the repository root (do not upload the folder itself or only a ZIP). Include `.nojekyll` if your file picker shows it.
3. In the repository open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/ (root)**, then **Save**.
6. Wait for the deployment to finish. Your address should be `https://abanoubmalak2005.github.io/`.

If this repository already exists, inspect it before making changes. Do not replace unrelated files. If the ChatGPT GitHub connection cannot see a newly created repository, update the connection's repository access in GitHub.

The website and repository source are public when published this way. Do not add passwords or private details to the files. The starter uses only your first name and public GitHub username, with no contact form or tracking.
